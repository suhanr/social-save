# Social Save

Static copy of https://socialsave.site/ (9 pages: home, social-media-downloader, youtube-downloader, free-stock-media, blog, about, contact, privacy-policy, terms).

HTML, CSS, JS, images and fonts are served from this repo with relative paths. Blog posts are not included, so links to them point to the original site. Server endpoints (search, comments, admin-ajax) are not available in this static copy.

Run locally: `python3 -m http.server 8080`
