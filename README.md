# Social Save

Static copy of https://socialsave.site/ (9 pages: home, social-media-downloader, youtube-downloader, free-stock-media, blog, about, contact, privacy-policy, terms).

HTML, CSS, JS, images and fonts are served from this repo using relative paths, so the site works from any base path (e.g. GitHub Pages at `/social-save/`). Blog posts are not included; links to them point to the original site. Server-side endpoints (search, comments, admin-ajax) are not available in this static copy.

Run locally: `python3 -m http.server 8080`
